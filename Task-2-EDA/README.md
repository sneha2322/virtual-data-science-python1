Task 2: Exploratory Data Analysis and Visualization

Project Overview

This task focuses on analysing student performance data using Python. Pandas was used for data inspection and statistical analysis, while Matplotlib and Seaborn were used to create visualizations.

Key Activities

- Dataset inspection and data quality checks
- Descriptive statistical analysis
- Final grade distribution analysis
- Study time, absences and gender-wise grade comparisons
- Average grade comparison across G1, G2 and G3

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn

Dataset

Student Performance Dataset — UCI Machine Learning Repository.

Deliverable

The internship report documents the analysis, visualizations, observations and conclusions.
