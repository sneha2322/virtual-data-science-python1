Task 3: K-Means Clustering

This folder contains the files related to Task 3 of my Virtual Data Science with Python Internship.

Objective
The objective of this task is to apply the K-Means clustering algorithm to group students based on their study time, past failures, absences, and previous exam grades.

 Files Included
- Python code for K-Means clustering
- Internship task report
- Graphs and visualizations
- Dataset used for clustering

 Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

 Outcome
The project applies K-Means clustering, evaluates different values of K, and analyzes the characteristics of the resulting student groups.
