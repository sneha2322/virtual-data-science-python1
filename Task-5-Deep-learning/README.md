 Task 5 – Deep Learning
 Object Classification Using CNN with CIFAR-10 Dataset

 Project Overview
This project focuses on developing an image classification model using Deep Learning and Convolutional Neural Networks (CNN).

The CIFAR-10 dataset was used to classify images into ten categories: airplane, automobile, bird, cat, deer, dog, frog, horse, ship and truck.

 Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
 Project Workflow
1. Loading the CIFAR-10 dataset.
2. Image preprocessing and normalization.
3. Splitting data into training and validation sets.
4. Designing a CNN architecture.
5. Compiling and training the model.
6. Evaluating model performance.
7. Generating a classification report and confusion matrix .
8. Saving the trained model.

Model Results
- Training Epochs: 15
- Test Accuracy: 74.89%
- Test Loss: 0.7685
- Total Test Images: 10,000

 Project Files
- `task_5.py` – Main CNN implementation.
- `evaluate_saved_model.py` – Saved model evaluation and confusion matrix.
- `cifar10_cnn_model.keras` – Trained CNN model.
- `Deep_Learning_Report.docx` – Detailed project report.

Conclusion
This project demonstrates the practical application of CNNs for multi-class image classification and provides experience in dataset preprocessing, model training and performance evaluation.
